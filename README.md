# Мафя (Mafya) — ИИ-компаньон с живым лицом (Android)

Анимированное лицо (глаза с ресницами, румянец, моргание, эмоции), голос, память, дневник, режим сна, напоминания.
Мозг — **Gemini 2.5 Flash через OpenRouter** (`google/gemini-2.5-flash`).

## Сборка APK через GitHub
1. Создай репозиторий (лучше **приватный**) и залей содержимое папки, включая скрытую `.github`.
2. Положи ключ OpenRouter в секрет: **Settings → Secrets and variables → Actions → New repository secret**,
   имя `OPENROUTER_API_KEY`, значение — твой ключ `sk-or-v1-…`. Ключ в код не пишется и в репозитории не светится.
3. **Actions → Build APK → Run workflow**. Готовый `app-debug.apk` — в Artifacts (`Mafya-apk`).

Секрет можно не добавлять: тогда после установки открой ⚙️ и вставь ключ вручную.
Учти: ключ, вшитый при сборке, можно вытащить из APK, поэтому не раздавай APK другим.

## Что умеет
| Функция | Как работает |
|---|---|
| Лицо и эмоции | Canvas: neutral, happy, stars, wink, surprised, heart, thinking, listening, sleep. Эмоцию выбирает модель |
| Голос | 🎤 — распознавание речи (ru-RU), ответы озвучиваются TTS (выключается в настройках) |
| Память | Мафя сама запоминает важное о тебе; смотреть и удалять — 🧠 |
| Дневник | При уходе в режим сна 🌙 пишет запись о дне — 📖 |
| Режим сна | 🌙 — лицо засыпает, касание будит |
| Напоминания | «Напомни завтра в 9 позвонить маме» → уведомление, переживает перезагрузку телефона |

## Файлы
`Face.kt` лицо · `Brain.kt` LLM и теги `[e:] [mem:] [remind:]` · `Voice.kt` микрофон/TTS · `Store.kt` хранилище ·
`Reminders.kt` уведомления · `MainActivity.kt` интерфейс.
